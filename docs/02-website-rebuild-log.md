# Website Rebuild Log

## Old Website / TradeWheel Issue

The original public web presence was not suitable for a long-term controlled brand website. TradeWheel-style visibility and older hosting created issues around ownership, consistency, SEO and professional B2B presentation.

The rebuild moved the website into a maintainable GitHub + Vercel workflow.

## New Website Purpose

The new site is designed to:

- Present Crystaring as a serious B2B glass lamp shade supplier.
- Support RFQ and catalogue requests.
- Provide product-category clarity for overseas buyers.
- Avoid exaggerated claims or unverified specifications.
- Create a base for SEO, GEO and AEO work later.

## Navigation Decisions

The public navigation was kept focused:

- Home
- Products
- OEM/ODM
- About
- Catalogue
- Contact / Quote

A mobile hamburger menu was added after testing showed mobile users could not access the main navigation from the header.

## Capabilities Page Removal

The standalone Capabilities page was removed from the public navigation strategy. Its content was merged into the About page, where factory and capability proof can support buyer confidence without adding another thin page.

The /capabilities/ route was handled with a redirect to /about/ or removed from public promotion, and it should not appear in sitemap.xml.

## About Page Role

The About page now carries:

- Company overview
- Factory context
- Who Crystaring works with
- Production and quality control information
- Conservative manufacturer credibility

The About page should remain buyer-facing. Avoid internal website-positioning language.

## Homepage Trust Strip

The homepage trust strip supports quick buyer confidence with concise B2B signals. Wording was corrected to avoid awkward capitalization and spacing, such as:

- Custom Sizes & Openings
- Export Packing for Fragile Glass

## Production And QA Notes

Production images and quality-control images were added carefully. Finished-light or electrical-testing imagery was removed because Crystaring is not publicly positioned as a finished lighting manufacturer.

Quality-control copy focuses on:

- visible defect checks
- surface inspection
- light table inspection
- dimensions
- openings
- finish
- inspection before packing
