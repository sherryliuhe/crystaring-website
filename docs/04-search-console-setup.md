# Google Search Console Setup

## Google Account

Google Search Console was set up using Sherry's Google account.

## Property Type

A domain property was used so Search Console can cover the domain broadly.

## Domain Verification

Domain verification was completed with a DNS TXT record.

The DNS was moved under Sherry's control and connected to Vercel. The final site uses the non-www canonical domain:

https://crystaring.com/

## Sitemap Submission

The sitemap was submitted in Google Search Console:

https://crystaring.com/sitemap.xml

There was an initial issue where the sitemap could not be fetched. It later reported successful status.

## Non-WWW Canonical Decision

The site uses the non-www version as canonical:

https://crystaring.com/

www.crystaring.com should redirect to crystaring.com.

Sitemap, robots and canonical tags should remain aligned with the non-www canonical domain.
