## Product Page Rules

Each product page should remain conservative and useful for B2B review.

Do:

- Use clear product images.
- Use model/SKU references when available.
- State category conservatively.
- Mark dimensions and openings as confirm-before-quotation where not fully verified.
- Keep specification notes buyer-facing.

Do not:

- Invent dimensions.
- Invent openings.
- Invent material.
- Invent MOQ.
- Invent lead time.
- Invent packing capability.
- Invent applications.

## Selected Sample Series Message

The product pages and category pages should communicate that images are selected product references for B2B sourcing review. Final specifications, tolerances and packing details are confirmed before quotation and production.
